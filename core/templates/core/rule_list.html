Exemplos e diferença entre cadastro e cálculo

Frota: cadastrar como provento não define valor por limpeza ou por mês. O DP ainda precisa aprovar a regra.

Pensão para conferência: use uma rubrica informativa sem pagamento quando o objetivo for apenas verificar o desconto já feito na folha.

12h: o nome da rubrica identifica o pagamento; o valor por ocorrência está na regra de cálculo. Não altere a classificação para tentar mudar o valor.

Combinado: é uma meta líquida informada pelo negócio. Cadastrar uma rubrica de provento não implementa essa garantia líquida.
